📋 Installation Steps

  1. Import Database Schema:
    Run the SQL file in phpMyAdmin or command line:
    mysql -u root -p lars_db < install_matching_games.sql
  2. Set Directory Permissions:
    Make sure the uploads directory is writable:
    chmod 777 uploads/matching_games/
  3. Test Modal Creation (NEW!):
    Teacher Dashboard → Activities Tab → "Create Game Activity" → Select "Matching Game"
    ✨ Now creates games in a modal without leaving the dashboard!
  4. Test as Student:
    Login → Games → Find matching games (🧩 icon) → Play!
  5. View Results:
    Teacher Dashboard → Manage Games → Click Results on any matching game
